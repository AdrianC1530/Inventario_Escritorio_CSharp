# Inventario de escritorio en C#

Aplicación de escritorio en **C# con Windows Forms** para administrar un inventario sencillo.

## Funciones

- Agregar elementos con nombre, marca, precio y cantidad.
- Modificar la cantidad de un elemento.
- Mostrar el inventario completo.

## Tecnologías

C#, Windows Forms, .NET Framework 4.7.2.

## Cómo ejecutarlo

Abrir `Proyecto5denuevo.sln` en Visual Studio y ejecutar con F5.
